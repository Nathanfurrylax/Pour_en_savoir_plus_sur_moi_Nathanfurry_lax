Connexion

Cette page modifie ton site directement sur GitHub. Il faut un « token » (une clé personnelle), qui reste uniquement dans ce navigateur.

Comment obtenir mon token ?
  1. Va sur github.com/settings/personal-access-tokens/new.
  2. Token name : par exemple « admin site ». Expiration : choisis la durée maximale.
  3. Repository access : « Only select repositories », puis choisis le dépôt de ton site.
  4. Permissions → « Repository permissions » → Contents : « Read and write ».
  5. Clique sur « Generate token », copie-le et colle-le ci-dessus.
